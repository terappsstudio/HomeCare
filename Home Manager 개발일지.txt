# HomeCare v3.0 개발일지

## 개발 기간

2026.07.22 ~ 2026.07.28

## 버전 목표

HomeCare의 기본 관리 기능을 안정화하고, 실제 태블릿 환경에서 사용할 수 있는 설치 관리 앱 형태로 완성하는 것을 목표로 개발.

---

## 주요 개발 내용

### 1. PWA 앱화

* GitHub Pages 배포 환경 구축
* manifest.json 적용
* Service Worker 적용
* 모바일/태블릿 홈 화면 설치 가능하도록 구성
* 앱 형태로 실행 테스트 완료

---

### 2. 도면 기반 위치 관리 기능

* 도면 이미지 업로드 기능 구현
* 도면 위 제품 위치 표시 기능 추가
* 마커 추가 및 이동 기능 구현
* 제품별 아이콘 적용

  * 방향제
  * 제습기
  * 기타 제품

---

### 3. 도면 조작 기능 개선

* 확대 / 축소 기능 추가
* 확대 비율 표시
* 도면 이동 기능 구현
* 마커 이동 시 위치 보정
* 태블릿 터치 환경 대응

---

### 4. 설치 기록 관리

* 제품 설치 기록 저장
* 설치 날짜 관리
* 교체 예정 관리 기반 구성
* 설치 내역 확인 기능 추가

---

### 5. 통계 화면 개발

* 통계 페이지 추가
* HomeCare 상단 위치 표시 적용
* 제품별 설치 현황 표시 구조 구성
* 향후 기간별 통계 확장을 위한 기반 마련

---

### 6. 화면/UI 개선

* 메인 화면 구조 정리
* 기록 / 통계 페이지 이동 구성
* 모바일 및 태블릿 화면 최적화
* 글자 크기 및 간격 조정

---

## 테스트 완료

* 모바일 환경 테스트

## HomeCare 개발일지 — v3.1 마무리

### 오늘 작업

* 공간 관리 기능 점검 및 안정화
* 공간별 도면 및 설치 마커 연동 확인
* 기록관리 화면에서 공간 목록 정상 표시 확인
* `record.js`의 `list` 중복 선언 오류 수정
* Service Worker 캐시 문제 확인 및 정리
* 메인 → 기록관리 이동 시 오류 발생 문제 해결
* 여러 공간(`우리집`, `테스트1`, `테스트2`) 데이터 정상 유지 확인
* 공간 불러오기 및 도면 표시 정상 작동 확인

### v3.1 현재 상태

공간 관리와 기록관리의 기본 연결 구조가 안정화되었으며, 주요 기능 정상 작동 확인.

**v3.1 Stable 단계 진입**

### 다음 단계 — v3.2

v3.1에서 구축한 기능을 기반으로 UI 및 사용성을 개선한다.

* 통계 화면 UI 개선
* 전체 설치 현황 / 공간별 설치 현황 구성 정리
* 화면 간격 및 버튼 등 전체 UI 다듬기
* 공간 관리 화면 사용성 개선
* 모바일 화면 최적화
* 필요 기능 추가 및 불필요한 요소 정리
